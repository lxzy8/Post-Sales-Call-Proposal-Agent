# Northstar Digital - Pricing Guidelines (INTERNAL ONLY)

## General Pricing Rules
- Pricing depends strictly on verified scope parameters, number of user seats, integration complexity, and data volume.
- **CRITICAL**: If the available information in a sales transcript is insufficient to determine scope parameters (e.g., exact CRM platform, number of integrations, team size, custom custom requirements), **DO NOT GUESS OR ESTIMATE A PRICE**.
- Output exact text when pricing parameters are missing or unclear:
  `Pricing requires manual estimation.`

## Reference Ranges (Internal Guidance Only)
- **Website Redesign**: $15,000 - $35,000 (Requires site page count and content readiness)
- **CRM Integration**: $10,000 - $25,000 (Requires CRM platform identity, user count, and legacy database complexity)
- **Lead Capture Automation**: $5,000 - $12,000 (Requires form count and notification channels)
- **Web Analytics Implementation**: $4,000 - $8,000 (Requires custom event list and dashboard specification)
